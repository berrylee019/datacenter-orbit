# 🌐 InfraPulse (Grid Aetheris)

> **Real-time Global Data Center & Power Infrastructure Intelligence Dashboard**

InfraPulse is an interactive prototype telemetry platform designed to track global AI data center workloads, grid saturation, and Small Modular Reactor (SMR) integration simulations.

## 🚀 Live Demo
Check out the live dashboard here: **[https://berrylee019.github.io/datacenter-orbit/]**

## ✨ Key Features
- **Global Infrastructure Map:** Interactive Leaflet.js map tracking high-density facilities (e.g., xAI Memphis Colossus, NAVER GAK Sejong).
- **Live Power Telemetry:** Simulated real-time grid load counters and PUE tracking.
- **SMR Integration Simulator:** Virtual zero-carbon grid coupling mechanism for next-generation AI data centers.
- **Responsive Architecture:** Built with pure vanilla HTML5/JS, Tailwind CSS, Leaflet.js, and Chart.js.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6)
- **Charts/Maps:** Chart.js, Leaflet.js
- **Icons:** Lucide Icons
